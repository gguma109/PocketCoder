# PocketCoder 0.7.0

Windows PC 화면·마우스·키보드·재생음을 Android 휴대폰과 태블릿에서 사용합니다.
Tailscale의 같은 사용자 계정으로 인증하며 공용 인터넷에 서버를 공개하지 않습니다.

## 설치와 연결

1. 성공한 [GitHub Actions 빌드](https://github.com/gguma109/PocketCoder/actions)에서 `pocketcoder-windows-installer`를 내려받고 ZIP 안의 설치 EXE를 실행합니다.
2. PC 설치본에는 Java 실행 환경, LGPL 공유 FFmpeg, PC 재생음 모듈이 포함됩니다. Java/FFmpeg 별도 설치가 필요 없습니다.
3. PC와 Android의 Tailscale에 같은 계정으로 로그인합니다. Tailscale 설치와 로그인은 사용자가 진행합니다.
4. 모바일은 `pocketcoder-android-apk`의 `app-release.apk`를 설치합니다.
5. PC 제어 창에서 **시작**을 누르고, 모바일 설정의 **PC QR 스캔으로 연결**로 QR을 읽습니다. QR에는 주소만 들어 있으며 비밀번호나 토큰은 없습니다.
6. 직접 연결하려면 PC의 **주소 복사** 값을 입력합니다. 한 번 연결한 주소는 저장됩니다.

기존 0.6.x 디버그 서명 앱에서는 한 번 삭제 후 설치해야 할 수 있습니다. 0.7.0부터는 고정 개인 서명키를 Actions Secrets로 공급합니다.
이후 같은 서명의 상위 버전 APK는 설정을 유지해 업데이트할 수 있습니다. 서명키와 비밀번호는 저장소/배포 파일에 포함하지 않습니다.

## 조작과 설정

- 여러 기기(최대 4개)가 같은 모니터 화면을 동시에 볼 수 있습니다. 같은 영상 프로필이면 하나의 인코더를 공유합니다.
- 먼저 연결한 기기가 조작권을 가집니다. 다른 기기는 **보기 전용**이며 **조작권** 버튼으로 가져옵니다. 기기마다 독립적인 PC 데스크톱을 만드는 기능은 아닙니다.
- 모니터 전환은 모든 시청 기기에 반영됩니다. 오래된 모니터 좌표의 입력은 무시합니다.
- 실제 표시 FPS, 영상 수신 Mbps, 네트워크 왕복 RTT, 입력 응답 시간, 앱 내 디코드 시간, 동시 시청 수를 표시합니다. 이 수치는 캡처부터 화면까지의 전체 지연을 뜻하지 않습니다.
- 기기별로 원본/균형/데이터 절약 화질, 최대 120/60/30 FPS, 5/15/40/80Mbps 상한을 저장합니다. 실제 FPS는 하드웨어·네트워크·디코더에 따라 달라집니다.
- 마우스 감도와 가속을 조절할 수 있습니다. **드래그 ON** 뒤 트랙패드를 누르고 움직이면 왼쪽 버튼을 누른 채 이동하며 손을 떼면 놓습니다. 취소·기기 전환·조작권 만료 시 버튼을 해제합니다.
- 휴대폰 기본 키보드로 한글/영문을 작성해 **전송**합니다. PC Delete·Backspace·Ctrl 단축키는 별도로 제공합니다.
- **PC 사운드 듣기**는 Windows 기본 재생 장치의 소리만 전송합니다. 마이크 캡처와 Android 마이크 권한은 없습니다. 켜기/끄기와 음량을 기기마다 저장합니다.
- 사운드는 16비트 스테레오 PCM이며 48kHz에서 약 1.54Mbps를 추가로 사용합니다. PC 기본 재생 장치가 있어야 하며 보호된 콘텐츠는 Windows 정책에 따라 캡처되지 않을 수 있습니다.

## PC 창과 업데이트

X/최소화는 트레이로 숨깁니다. 트레이 메뉴에서 서버 시작·종료, 창 열기, 프로그램 끝내기를 선택합니다.
설치/제거/업데이트는 해당 설치 폴더의 서버만 종료합니다. 다른 Java 프로그램은 종료하지 않습니다.
PC와 모바일은 하루 한 번 또는 수동으로 마지막 **성공한** Actions 빌드의 업데이트 정보를 확인합니다.
업데이트 다운로드에는 GitHub 로그인이 필요할 수 있습니다. 자동 설치하거나 서버를 임의 공개하지 않습니다.

## 개발 및 검증

Android: Java 17 / Gradle 8.9 / SDK 35 / minSdk 26. `gradle -p android-client :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`
서버: `gradle -p desktop-server serverJar selfTest`.
Windows 설치본은 Inno Setup의 사용자별 설치 모드이며 bundled runtime 자체 테스트·사운드 변환 테스트·무인 설치/제거 검사를 CI에서 실행합니다.
FFmpeg 바이너리는 체크섬을 고정하고 LGPL 공유 빌드인지 확인합니다. 배포본의 `third-party`와 `runtime/legal`에 라이선스·소스·빌드 정보가 있습니다.

## 보안

- 직접 HTTP는 신뢰하는 LAN 전용입니다. 외부 접속은 Tailscale 암호화 터널을 사용합니다.
- 서버는 wildcard/public IPv4 바인딩을 거부합니다. TCP 8765를 포트포워딩/Funnel/공용 터널로 인터넷에 공개하지 마세요.
- 실제 접속 IP를 로컬 Tailscale 서비스에 조회해 같은 사용자 소유 기기인지 확인하며 실패하면 거부합니다.
- QR과 조작권 ID는 인증 수단이 아닙니다. 모든 화면·입력·소리·조작권 API는 동일한 서버 인증을 거칩니다.
- 쉘 명령 실행 API나 파일 실행 기능을 추가하지 않습니다. 재생음 도우미와 FFmpeg는 고정된 로컬 실행 파일만 사용합니다.
- 카메라 권한은 QR 스캔 시에만 요청합니다. 거부해도 주소 입력으로 연결할 수 있습니다.
